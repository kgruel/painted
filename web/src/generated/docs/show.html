Guide 0 — Display data

You have data and want it to look decent in a terminal. show() is the whole API at this rung: it auto-dispatches by data shape — dict to key-value, list to items, numeric to chart, nested to tree.

from painted import show

show({"status": "ok", "items": 42})

show(data, zoom=Zoom.DETAILED) asks for more, show(data, zoom=Zoom.MINIMAL) for a one-liner. That zoom argument is the first rung of the disclosure ladder — the same axis -q/-v will control once you have a CLI.

Why start here

Every later rung is additive. A show() call you outgrow becomes a render function without rewriting what it displays — the no-framework-switch invariant.
