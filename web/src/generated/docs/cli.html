Guide 2 — A CLI tool

You need -v/-q, --json, pipe detection, and help text. Write two functions — render(ctx, data) -> Block and fetch() -> data — and run_cli owns the rest: flag parsing, TTY detection, mode dispatch.

from painted import run_cli, CliContext, Block

def render(ctx: CliContext, data: dict) -> Block:
    return status_view(data, zoom=ctx.zoom, width=ctx.width)

run_cli(sys.argv[1:], render=render, fetch=fetch)

The disclosure ladder

Each rung is additive; climbing never rewrites the rung below.

depth
gate detail on ctx.zoom — -q/-v/-vv come free
tags
declare Tag("thinking", "...", implied_at=3); gate on ctx.fidelity.shows("thinking") — the flag, help entry, and implication are generated
budgets
pass budgets=True; read fidelity.chars/.lines — only now do --max-chars/--max-lines exist

Depth is anonymous detail; a tag is a named facet a user would ask for at low depth (--thinking at -q). The honesty rule: a flag exists only because a capability was declared, and a declared capability must change output.

The other two axes resolve without you: Format (--json/--plain, ANSI for TTY, PLAIN for pipes) and Mode (--static/--live, AUTO from TTY state). depth_aliases={'brief': 0, 'full': 3} adds app-local depth spellings.
